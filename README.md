# Prerit — MacBook 3D Portfolio

Premium single-page portfolio for a full-stack developer + graphic designer.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm start
```

## Customize

Edit `app/page.tsx` for your profile, projects, links and contact information.

Replace the placeholder PR portrait and project visuals with real assets in `public/`.
